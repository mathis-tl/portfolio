Trois chantiers : la fiabilisation des flows planifiés qui synchronisent les outils internes (erreurs qualifiées, reprise ciblée), une recherche automatique de prix publics comparables avec un scoring explicable et une revue humaine, et l'auto-formatage d'offres fournisseurs Excel. L'idée directrice : l'IA lit, le code garantit, l'humain tranche.

Outils utilisés pendant le stage : Python et SQL pour les traitements, Prefect pour l'orchestration, Supabase pour le stockage, Retool pour l'outil d'analyse des achats, Airtable et Google Sheets pour les données validées, l'API OpenAI pour lire la structure des fichiers, avec des tests unitaires et un harnais de non-régression.

Les démonstrations du dépôt utilisent des produits et des fichiers fictifs. Elles ne reprennent pas le code, les données ni les accès de l'entreprise.

Source : CV et rapport de stage de Mathis Telle, README github.com/mathis-tl/mathis-tl et README github.com/mathis-tl/willy-antigaspi-data-internship.
